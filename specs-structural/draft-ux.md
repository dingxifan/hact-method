# task: draft-ux

**discipline**: product
**Gate**: 无独立 Gate；PRD 标 draft-ux:需要 时为 G2 前置
**属性**: version

从已确认 PRD 的用户目标出发，设计跨功能完整动线，产出可操作原型并完成 AI/独立走查与用户体验确认。

## 前置条件

G1 已签；本期有需确认的新页面或核心交互。纯后端无用户交互时按 PRD 标记跳过。用户任务不等于开发包、功能或页面。

## 产物与接口

| 产物 | 内容 |
|---|---|
| iterations/vN/ux-flows.md | 场景列表按「### 用户任务：U1 名称」分组，含目标/起点/完成/相关功能及 S-id 场景；第二段是流程图 |
| iterations/vN/prototype.html | 自包含、连贯数据与状态，可从入口走到任务结果并验证相关失败/取消/恢复 |
| iterations/vN/prototype-map.md | AC→用户任务/场景/锚点/页面规格的多对多映射、排除理由、动线证据索引与用户确认 |
| iterations/vN/ux-evidence/ | 浏览器动作/结果及对应原型版本证据；不含真实业务数据或凭据 |
| design.md | 全局视觉基线及实际页面规格；页面与 PRD 功能不要求同名或一一对应 |
| design-brief.md（条件） | 用户明确选外部设计会话时才产出；同样按用户任务组织 |

## 完成判据

- [ ] 用户目标、起点、完成结果明确；必要信息在判断前出现，关键路径无多余跳转或重复输入
- [ ] 每个核心任务可从真实入口完成；相关失败、取消、返回、未保存离开和中断恢复已实际验证
- [ ] PRD AC 全部有覆盖或合理排除；映射引用的 U/S/id/页面真实存在
- [ ] 动线浏览器证据对应当前原型；结构检查通过不代替真实执行
- [ ] 无设计叙事继承的独立审查已完成，重要缺口已修复或有明确产品裁决
- [ ] 用户明确接受当前版本的逻辑与体验；后续改动若使接受失效，重新确认受影响任务
- [ ] design/动线/原型/映射一致，必要文件已提交，任务目标与分支可供 TRD/开发/集成验收引用

具体做法与例外见 specs-execution/draft-ux.md。
