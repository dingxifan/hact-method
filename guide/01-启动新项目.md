# 情境：启动一个新项目

> 适用于：第一次为一个新项目建立工作环境。完成后，团队可以开始写 PRD。

---

## 这个阶段做什么

建立项目的"地基"：本地目录结构、初始配置文件、Gitee 远端仓库、连接与凭据登记、项目共识讨论（填地基蓝图）。

完成后，项目就进入可操作状态——有地方放文件，地基蓝图已立；只有存在稳定且晚建代价高的跨切面约束才走 V0，否则直接写 PRD。

**AI 做 / 你做**

| AI（Codex）做 | 你做（需要手动） |
|---|---|
| 创建完整本地目录结构和初始文件 | 说清楚项目叫什么、大致做什么 |
| git init + 首次 commit + git push | **在 Gitee 手动创建空仓库**，把地址告诉 Codex |
| 播种 `connections.yml` + 校验连接凭据 | 首次配置时提供 Gitee Token（一次性，落 `~/.hact/secrets.env`） |
| 引导项目共识讨论、填 `foundation.md` | 讲清楚项目全貌与核心实体 |

---

## 步骤

### 第一步：告诉 AI 要新建一个项目

打开 `hact-method` 目录，使用 Codex 启动新会话，直接描述就好，不用套格式。比如：

> "我要新建一个项目，叫 mail-ai，是一个给团队用的邮件协作工具。"

Codex 会按同一 `init-project` 规范立项，并在与方法论仓同级的 `{工作区根}/{项目名}/` 创建以下结构：

```
{项目名}/
├── iterations/
│   └── v1/
│       └── queue/              ← 任务包放这里（plan-sprint 后由 Codex 填充）
│           └── done/
├── _meta/
│   ├── input/                  ← 背景材料、上下文文档
│   └── sessions/               ← 跨会话接续文件
├── gitee-ops.md                ← Gitee API 操作说明
├── .codex/
│   └── agents/                  ← Codex 调查/实现/普通审查/敏感审查配置
├── scripts/
│   └── check-codex-project.js ← Codex 入口与配置只读诊断
├── project.md                  ← 跨迭代项目快照
├── decisions.md                ← 架构决策记录
├── design.md                   ← 视觉规格
├── reusables.md                ← 可复用资产
├── backlog.md                  ← 积压与偏离
├── feedback.md                 ← 各阶段反馈
└── AGENTS.md                   ← Codex 薄入口，显式读取共同协议
```

> `prd.md`、`trd.md` 等设计文件不是占位创建的，而是由后续各任务运行时生成：写 PRD 时才有 `prd.md`，写技术方案时才有 `trd.md`，以此类推。

### 第二步：在 Gitee 手动创建空仓库

这一步需要你自己操作：去 Gitee 新建一个仓库，**不要勾选"初始化仓库"**（保持空仓库），然后把仓库地址告诉Codex（格式如 `https://gitee.com/{你的账号}/{项目名}.git`）。

Codex 拿到地址后会自动完成剩余工作：绑定远端、首次推送。

---

## 完成标志

- [ ] 本地目录结构完整
- [ ] 推送到 Gitee，远端仓库可见
- [ ] `connections.yml` 已播种，`node scripts/check-conn.js check` 通过
- [ ] `node scripts/check-codex-project.js` 通过，Codex 入口与角色配置形状齐备
- [ ] `foundation.md` 领域地图与地基关注点已填
- [ ] 团队成员权限配置完毕

完成后，进入下一步：[一期完整流程](02-一期完整流程.md)，开始写 PRD。

存量项目不批量覆盖入口或配置。先在目标仓运行 `node ../hact-method-lab/templates/scripts/check-codex-project.js --root .` 只读列缺口（直接使用已同步的方法论当前版诊断器），再逐仓获得授权后按 Codex 模板逐项合并补齐。
