# 个人积累（可选）

个人笔记不是立项、开发完成或 G5 的前置。方法论不要求为每位成员建仓、登记游标、分类誊写或提交笔记。用已有工具即可，不必新建仓。

只有用户明确要求时，才创建/访问指定私人资料，并核对真实读写授权；不凭组织管理员身份推断访问许可。不自动收割他人内容，不回写来源，不把个人经验直接升为团队规则。

可复用发现留在当前项目 feedback 或 PR 引用即可；具体功能缺口仍留项目 backlog 并处理，不用私人笔记替代待办。按需整理公共经验时使用 `specs-execution/harvest-notes.md`。

本次只退役强制工作流，不删除、迁移或改变任何现有私人仓的权限。
