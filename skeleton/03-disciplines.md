# 可选知识分类

`discipline` 仅帮助查找任务知识，不是用户身份、拉取准入、审批角色或模型分配协议。执行路由仍由 task.type 决定；无需为每人登记学科或在任务中同步派生学科。

| 分类 | 关注内容 |
|---|---|
| management | 目标、授权边界与必要收尾 |
| product | 用户任务、业务意图与验收 |
| architecture | 共享契约、跨切面约束与技术取舍 |
| dispatch | 任务范围、依赖与写集冲突 |
| integration-testing | 组合行为、端到端证据 |
| dev-frontend | 界面实现、用户动线与前端验证 |
| dev-backend | 服务实现、数据与契约验证 |
| deploy | 环境、发布与恢复证据 |

这些分类不禁止同一执行人跨层工作。主线可直接实现，是否委派按独立性与收益判断；首次独立审查须隔离实现历史，详见 develop。权限规则见 `01-identity.md`，不在本表另造授权。
