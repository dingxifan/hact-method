# exec: harvest-notes（可选）

仅在用户明确要求整理经验时运行，不是立项、develop 或 G5 的依赖。不要求全员私人仓、登记表或收割游标。

1. 确认本次指定来源及读取/引用许可；可以是已有项目反馈、PR 或用户主动提供的笔记。不枚举或自动访问未获授权的私人资料。
2. 只读提取有证据、可复用的发现，保留来源；区分事实、分析与候选建议，不把个人偏好变成强制规则。
3. 项目具体缺口留原项目待办，公共方法建议可在本仓授权范围内写入 `_meta/plans/方法论待议.md`；实际规则变更另按其影响评估验证，不由收割动作自动批准。
4. 简报本次采纳/未采纳的理由与产物。无有价值发现可以零产出；不回写来源、不清空私人资料，不为了归档而另造任务。

恢复时根据已提交产物与来源引用继续，不要求登记永久游标。不具备来源许可只跳过该来源并说明，不阻断项目开发。
