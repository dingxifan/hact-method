# 方法论过度设计纯减法

> 日期：2026-09-04
> 分支：`codex/methodology-overdesign-reduction`
> 范围：不改 V0、Gate、独立审查或最终验证，只减少启动与审计中的重复劳动。

## 交付项

| 项目 | 状态 | 验收 |
|---|---|---|
| 能力预检后移 | ✅ | 先推断 `task.type`，再只检查该任务需要的能力 |
| 删除派生分钟字段 | ✅ | 不再持久化 implementation / review / round 派生分钟；由时间戳计算 |
| 压缩 freshness 正常路径 | ✅ | `pass` 只留固定锚与摘要；发生漂移才展开逐面证据 |
| 一致性验证 | ✅ | 检查器、夹具、运行时中立与交接演练全部通过 |

## 不变量

1. V0 仍由人类在 init-project 中自主决定走或跳。
2. 首轮独立完整审查、整改 targeted review、固定 diff 与末端全量验证不变。
3. `spec_minutes` 作为可能跨多段累计的规格墙钟继续保留；可由时间戳直接计算的分钟字段删除。
4. 不分发到任何项目仓，不覆盖存量入口或 hook。
