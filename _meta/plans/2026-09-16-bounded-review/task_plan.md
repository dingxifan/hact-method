# 独立审查范围与收敛调整

用户已授权制定计划并逐项落实，随后授权提交推送到当前方法论分支 `codex/context-reduction`。仅调整方法论仓，不修改项目代码、历史审查报告、Gate 或 hook，不分发项目仓。

## 决策

- 保留 PRD、UX、TRD、规划、开发和联调各自职责；开发首审三个核心问题，专项由审查员按真实改动独立触发。
- 同一独立审查员默认接续；不参与实现；复审只核问题、增量和影响，确凿新问题可报，扩审须有失效依据。
- 证据须匹配实现、依赖/配置、执行路径和环境；允许独立核验执行者的原始日志，不采信自评代替证据。
- 同快照补证仍使用 round 报告，仍计 code_rounds、仍受三轮上限，不新增阶段或旁路。
- 新报告声明 review_policy: bounded-v1；检查器从该轮起核结论一致性，旧报告原样保留并按原规则核验，不追溯重写。声明后不得退回旧策略。
- 纯补证须 targeted、显式 evidence_only、相同 Git tree 和有效证据文件；实现或测试变化必须普通增量复审。
- 机械字段工具生成；不新增 profile、全维度覆盖表或工时填报。
