# GPT-5.6 双运行时适配

> 开始日期：2026-09-04
> 分支：`codex/5_6_runtime_refresh`（从 `master@7c28db4` 创建）
> 范围：让 Claude Code 与 Codex 在同一项目仓共享任务包、Gate、状态和审查证据；不为运行时 fork 流程。

## 不变量

1. `task.type` 仍是任务路由键；运行时仅属于会话层，绝不进入 `status.yml`、任务包或 Gate 判据。
2. 运行时专属实现只住映射表；执行规范、结构契约和审查 brief 只描述中立能力接口。
3. 两个运行时写入同一组产物与同一检查器。跨运行时交接只依赖仓库文件，不依赖聊天记忆。
4. 独立审查必须有隔离上下文和自读权威原文；同一执行会话的复查不能冒充独立审查。
5. 共享资产未声明读写范围与依赖时，不允许并发写。
