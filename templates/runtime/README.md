# 运行时适配层

本目录只定义运行时能力的**共同语义**与各运行时的**实现映射**。它不拥有任务状态、Gate、任务包或检查器的业务契约。

| 文件 | 职责 | 谁读取 |
|---|---|---|
| `interfaces.md` | 中立能力定义、产物不变量与降级规则 | 所有执行规范和入口 |
| `preflight.md` | 任务路由确定后的运行时声明复述与按需能力协商 | 共同启动协议 |
| `cc.md` | Claude Code 的具体实现映射 | `CLAUDE.md` 入口 |
| `codex.md` | Codex 的具体实现映射 | `AGENTS.md` 入口 |

规则：正文只引用 `interfaces.md` 中的能力名；实现命令、模型、工具名只可出现在 `cc.md` 或 `codex.md`。运行时标识可出现在入口与预检，但不得写进 `status.yml`、任务包或 Gate。
