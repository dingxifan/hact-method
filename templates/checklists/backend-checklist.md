# 后端验证要点

本清单用于选择本次改动的验证面，不要求逐类造测试或另交自检报告。结果写已有任务/审查记录。

- 按原始契约验证输入、输出、错误与状态变化；覆盖真实边界，不能从实现抄期望。
- 涉及权限/数据隔离、迁移、并发、幂等或外部副作用时，验证对应失败与恢复路径。
- 外部输入和持久化 JSON 在使用边界校验；错误经过统一转换后仍有正确机读语义，日志不泄露隐私/凭据。
- 类型/lint/测试已有有效覆盖时复用；配置存在不等于命中了违规，变更检查机制时核正反例与实际接线。
- 按实际差异检查查询放大、共享口径重复和跨模块接缝；无关类别不展开、不写 N/A 表。
- 只对变化、失败或具体疑点补验证；既定必要检查通过即可进入独审/收尾，不反复全仓测试。
