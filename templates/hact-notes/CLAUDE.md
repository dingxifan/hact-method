# 个人积累仓 · hact-notes-{姓名}

这是 {姓名} 的**私有个人积累仓**——hact-method 方法论的"个人积累"工作区（见 `../hact-method/skeleton/02-workspaces.md` §4）。

## 这个仓是什么
- 随手记开发中的经验：踩坑、想沉淀的规范、自检漏项、方法论吐槽、个人心得。
- **私有**：只有你能 push，别人读不到。管理者经 `harvest-notes` 只读收割可上提的条目。

## 怎么用
- 所有内容写进 `notes.md`，按标签约定一行一条（见 `notes.md` 头部）。
- 写完自己 `git add notes.md && git commit && git push`。
- **不碰 hact-method、不碰项目仓**——本仓只管你自己的积累。

## 上提（pull 模型）
- `[规范]` / `[checklist]` / `[方法论]` 会被管理者的 `harvest-notes` 收割、去重择优后上提到公共层（团队下期可用）。
- `[心得]` 永不上提，纯私有。
- 上提是拉取式：你不需要、也无权 push hact-method。
