# 后端编码规范（通用模板 · 栈无关）

> 项目启动时由 draft-foundation（V0 首播）/ draft-tech-design（存量兜底）挑选本期相关项，播种到**项目根** `standards-backend.md`（跨迭代活文档，vN+1 原地增补）。
> **本文件只保留栈无关的原则与纪律**；栈特定写法（ORM 细则 / 校验装饰器 / 框架陷阱）见对应**栈子模板** `backend-{栈}.md`（如 `backend-nestjs.md`），播种时按 `project.md` 技术层选用并与本文件叠加。项目用的栈无子模板 → 仅用本文件，栈特定约定直接写项目根 standards。
> 通用规则在此维护；项目特有规则写在项目根 standards-backend.md 末尾，不要改这里。

---

## 分层规范（强制）

- Controller（路由层）只做请求接收和参数传递，**禁止在路由层写业务逻辑判断**
- 业务逻辑全部在 Service 层
- **禁止路由层直接操作数据库**，必须经过数据访问层（Repository / DAO，形式按项目栈）
- 禁止在 Service 层直接操作 response 对象，统一由框架层（拦截器 / 中间件）处理

## 响应格式规范（强制）

- 业务代码直接 return 数据，**禁止手动包装 `{ code, msg, data }`**
- 成功响应由框架层统一格式化；异常由统一异常处理层捕获，业务代码不直接操作 response 对象（具体机制名称见栈子模板）

## 入参验证（强制）

- 所有请求入参**必须有显式的 schema 级校验**（必填性 + 类型），机制按项目栈（装饰器 / schema 校验器），禁止用隐式类型转换替代显式验证
- 外部 API 返回值（第三方 SDK）必须检查关键字段是否为 null/undefined，不能直接解构
- **警惕"校验形同虚设"**：入参对象没接上校验机制时框架往往静默放行（栈子模板列出本栈的具体触发形态），非法值会静默进入下游转换，产生极难排查的错误

## 安全规范（强制）

- 禁止硬编码密钥、密码、API Key，统一通过环境变量注入
- 禁止明文存储任何凭证类数据，加密方案在项目 standards-backend.md 中指定
- 响应数据中禁止出现 `password`、`secret`、`token` 等敏感字段明文
- 需要鉴权的接口必须挂鉴权守卫 / 中间件，不得遗漏（具体机制见栈子模板）
- 附件/文件下载接口必须校验资源归属用户，防止越权访问

## 日志规范

- 禁止在日志中打印用户隐私数据（邮件正文、密码、token 等）
- 禁止在日志中记录用户输入内容（尤其是 AI 相关日志）
- 错误日志必须记录具体原因，不能只 `catch` 不记录

## 数据库规范

- 禁止 N+1 查询：关联数据一次性加载（本栈写法见栈子模板）
- 有唯一性要求的字段必须在模型层声明唯一约束，同时确认数据库层 UNIQUE KEY 实际生效
- upsert 操作需验证唯一约束实际有效（本栈陷阱见栈子模板）

### JSON 字段类型守卫（强制）

- **数据库中的 JSON 字段，运行时类型不可信，必须在读取后立即用类型守卫验证，不得依赖编译时类型**
- 格式异常的 JSON 字段若不守卫，会静默进入下游逻辑，可能导致数据腐蚀
- 示例（TypeScript）：
  ```ts
  function isRecurrenceRule(v: unknown): v is RecurrenceRule {
    return !!v && typeof (v as any).type === 'string' && typeof (v as any).interval === 'number'
  }
  if (!isRecurrenceRule(record.recurrenceRule)) continue
  ```

## 定时任务规范

- 定时任务里的日期比较必须明确时区口径，禁止混用 UTC 取值和本地时取值（本栈已知陷阱见栈子模板）
- 日期加减注意月末溢出等边界（本栈修正写法见栈子模板）

## 部署规范

### 双层防火墙均须开放

服务器通常有两层防火墙：云控制台安全组 + 服务器 UFW。两层都会拦截流量，任意一层未开放都会导致 502 / connection refused。

新端口上线前，必须同时确认：
1. 云控制台安全组中已添加该端口
2. 服务器执行 `sudo ufw allow <port>/tcp` 并 `sudo ufw reload`

## 代码整洁

- 禁止提交含 `// TODO`、`// FIXME` 的未完成代码
- 禁止遗留调试输出（`console.log` 等，统一走项目日志器）
- 禁止提交注释掉的废弃代码块
- 禁止未使用的 import
