# 前端编码规范（通用模板 · 栈无关）

> 本文件是候选规则库。draft-foundation 只取 V0 骨架实际命中项；首期 draft-tech-design 再按真实 PRD/TRD 补齐适用规则。条目须过 `schema.md` 准入，带稳定 id 与 `applies-if`；禁止整节复制或按版本追加。
> **本文件只保留栈无关的原则与纪律**；栈特定写法（组件规范 / UI 库陷阱 / 状态库 / 构建工具）见对应**栈子模板** `frontend-{栈}.md`（如 `frontend-vue3.md`），播种时按 `project.md` 技术层选用并与本文件叠加。项目用的栈无子模板 → 仅用本文件，栈特定约定直接写项目根 standards。
> 通用候选在此维护；色彩值、断点值、业务状态枚举等本期契约回 design.md/PRD/TRD，不进入项目 Standards。

---

## 设计系统（强制）

- 禁止硬编码颜色值（如 `color: #333`），统一使用样式变量（SCSS 变量 / CSS custom property，形式按项目栈）
- 禁止硬编码间距（如 `margin: 20px`），统一使用间距变量（8px 网格）
- 项目启动时在单一全局变量文件（如 `variables.scss`，路径按项目栈）中定义色彩和间距变量，后续所有样式引用变量
- **全局样式入口（单一）**：必须有单一全局样式入口（应用入口文件引入 `reset` + 全局变量文件），`html`/`body`/`*` reset 等地基样式只在此处声明；禁止各组件各写 `body`/全局样式（否则 body margin、视口外溢这类地基活无人兜底、十几处各写一份）
- **UI 库主题覆盖**：使用 UI 组件库时，必须用 design.md token 覆盖其主题变量（把设计主色映射进库的主题变量——具体变量名按项目 UI 库，见栈子模板），**禁用库默认主色/默认主题**；覆盖集中在全局入口或单一主题文件。「定义了 token 但没覆盖库主题」= 全站主色仍是库默认
- 以上「全局入口 + 主题覆盖 + token 接线」是**视觉地基包**的内容，由 plan-sprint 在 v1 拆为前端首包统一落地（见 plan-sprint Step 2）

### 间距（8px 网格，不得自造数值）

```scss
$space-xs: 4px;  $space-sm: 8px;  $space-md: 16px;
$space-lg: 24px; $space-xl: 32px; $space-xxl: 48px;
```

- **禁止使用设计系统变量之外的间距数值**：就近向上取整到已定义的变量
- 低于 4px 的间距应当质疑是否合理

### 字号

```scss
$font-size-h1: 32px; $font-size-h2: 24px; $font-size-h3: 18px;
$font-size-body: 16px; $font-size-caption: 14px; $font-size-small: 12px;
```

> 变量声明语法按项目栈（上为 SCSS 示例），数值体系栈无关。

## 异步请求规范（强制）

- **任何异步请求失败必须有用户可见反馈**：禁止只处理成功路径、错误静默吞掉（含"只写 finally 不写 catch"——网络错误会向上抛出且无用户反馈）
- **错误反馈透传后端错误信息**，禁止写死错误文案
- loading 状态统一在 finally（或等价收尾时机）中重置
- 具体写法（错误提示组件 / 表单验证 API）见栈子模板

---

## 响应式规范

- 响应式断点由项目在全局变量文件中定义
- 所有弹窗：移动端 `width: 95vw`
- 所有右侧抽屉：移动端 `width: 100%`
- 输入框 `font-size`：移动端不低于 `16px`（低于 16px 在 iOS 触发页面放大）
- 按钮最小点击区域：`44px × 44px`，禁止用 `margin: -Npx` 扩大点击区域
- 禁止在包含 `overflow-x: auto` 的 flex 祖先上设置 `overflow: hidden`
- 表格必须用 `overflow-x: auto` 的 wrapper 包裹，防止移动端横向溢出
- Flex / Grid 多列布局必须有移动端单列降级

## 状态管理原则

- **跨页面刷新需保留的状态必须持久化**（初始化时读回、写入时同步落盘）
- **退出登录必须重置所有业务状态**，防止脏数据在下次登录时残留
- 具体 store 库写法见栈子模板

---

## 工具函数（从这里引入，不要重复实现）

- **凡是 `Date → 字符串` 的转换，先查项目统一格式化工具模块**（如 `@/utils/format.ts`），不要自行拼接
- 工具模块中没有的，先添加进去再引用，不要在组件内内联实现

---

## 常量管理

- **Token key 必须复用统一常量**：路由守卫、composable、工具函数中凡涉及本地存储 token 读写，必须引用统一定义的 `TOKEN_KEY` 常量，不得在各处硬编码字符串（如 `'token'`）。key 名变更时只改一处，避免静默不一致。

## 代码整洁

- 禁止提交含 `// TODO`、`// FIXME` 的未完成代码
- 禁止未使用的 import
- 禁止遗留 `console.log`
- 禁止提交注释掉的废弃代码块
